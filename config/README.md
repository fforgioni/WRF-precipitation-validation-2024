# WRF Model Configuration

This directory contains the WRF and WPS configuration files used in the four numerical experiments.

## Experiments

- GF-ERA5: Grell-Freitas with ERA5 forcing.
- GF-GFS: Grell-Freitas with GFS forcing.
- KF-ERA5: Kain-Fritsch with ERA5 forcing.
- KF-GFS: Kain-Fritsch with GFS forcing.

The configuration files document the numerical setup, spatial domain, temporal integration, and physical parameterizations.
