# Verification

This directory contains the statistical results
obtained from the WRF precipitation validation
study of the April–May 2024 extreme rainfall
event in southern Brazil.

The results include:

- Station-based verification metrics.
- Hourly precipitation diagnostics.
- Categorical verification statistics.
- Fractions Skill Score (FSS).

These results are generated by the analysis
scripts available in the `scripts/` directory.

Intermediate numerical arrays and large
NetCDF files are not distributed through
this repository.
