# Analysis scripts

Python scripts developed for the spatial, temporal,
statistical, categorical, and scale-dependent verification
of WRF precipitation simulations during the April–May 2024
extreme rainfall event in southern Brazil.

## Script overview

| Script | Description |
|---|---|
| `01_study_area.py` | Study area, topography and meteorological station distribution |
| `02_accumulated_precipitation.py` | Event-total precipitation fields |
| `03_spatial_bias.py` | Spatial precipitation bias relative to MERGE |
| `04_station_metrics.py` | Calculation of station-based verification metrics |
| `05_station_metrics_maps.py` | Spatial visualization of station-based metrics |
| `06_statistical_comparison.py` | Boxplots and density scatter plots |
| `07_hourly_analysis.py` | Hourly precipitation and temporal verification |
| `08_categorical_verification.py` | Categorical verification at different precipitation thresholds |
| `09_fractions_skill_score.py` | Scale-dependent precipitation verification using FSS |

## Requirements

Create and activate the computational environment
from the repository root:

```bash
conda env create -f environment.yml
conda activate wrf-validation
```

Input datasets must be placed in the `data/` directory.

See [Data requirements](../data/README.md)
for filenames, formats and temporal conventions.

## Execution order

Run the scripts from the repository root:

```bash
python scripts/01_study_area.py
python scripts/02_accumulated_precipitation.py
python scripts/03_spatial_bias.py
python scripts/04_station_metrics.py
python scripts/05_station_metrics_maps.py
python scripts/06_statistical_comparison.py
python scripts/07_hourly_analysis.py
python scripts/08_categorical_verification.py
python scripts/09_fractions_skill_score.py
```

## Script dependencies

The following dependencies must be respected:

- Script 03 requires the accumulated precipitation
  fields generated by script 02.
- Script 05 requires the statistical workbook
  generated by script 04.

All remaining scripts can be executed independently,
provided that their required input datasets are available.

|---|---|

| End time | 12 UTC |
| Daily accumulation window | 12–12 UTC |
| WRF horizontal resolution | 12 km |

## Verification methods

### Station-based verification

- Pearson correlation coefficient.
- Mean Bias.
- Root Mean Square Error (RMSE).
- Probability of Detection (POD).
- False Alarm Ratio (FAR).

Precipitation detection threshold: 1 mm/day.

### Categorical verification

- Critical Success Index (CSI).
- Probability of Detection (POD).
- False Alarm Ratio (FAR).

Daily precipitation thresholds:

- 20 mm/day.
- 50 mm/day.
- 100 mm/day.

Analysis window:
30 April 2024, 12 UTC – 1 May 2024, 12 UTC.

### Scale-dependent verification

Fractions Skill Score (FSS) is calculated using
MERGE as the reference precipitation dataset.

Daily precipitation thresholds:

- 10 mm/day.
- 25 mm/day.
- 50 mm/day.
- 100 mm/day.

Spatial neighbourhood sizes:

| Grid points | Nominal spatial scale (km) |
|---|---|
| 1 | 12 |
| 3 | 36 |
| 5 | 60 |
| 7 | 84 |
| 9 | 108 |
| 11 | 132 |
| 15 | 180 |
| 21 | 252 |
| 25 | 300 |

## Output directories

The scripts generate two main types of outputs:

- `figures/`: scientific visualizations.
- `results/`: statistical tables and intermediate
  numerical results.

Output directories are created automatically
where required.
